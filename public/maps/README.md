# Continent Maps

This folder should contain static continent map images with labeled countries and capitals.

## Required Files:
- `europe.png` - Europe map
- `asia.png` - Asia map
- `africa.png` - Africa map
- `americas.png` - Americas (North + South) map
- `oceania.png` - Oceania map

## Recommended Style:
- Colorful countries (different colors for each)
- Country names labeled on the map
- Capital cities marked with dots
- Clear, simple, static images (no interactions needed)

## Free Map Resources:

### Best Options:

1. **Vemaps.com** - https://vemaps.com/
   - Maps in AI, EPS, PDF, SVG, JPG, PNG formats
   - Organized by continent
   - High quality and free

2. **SimpleMaps.com** - https://simplemaps.com/resources/svg-world
   - Free SVG world maps
   - Commercial use allowed
   - Robinson projection

3. **Figma Community** - https://www.figma.com/community/file/1249864674191040289/world-map-and-continent-w-country-names
   - High resolution SVG maps
   - Countries labeled
   - Can export as PNG

4. **Facts Institute** - https://factsinstitute.com/countries/printable-world-map/
   - Public domain maps
   - SVG and PNG versions
   - Robinson projection

5. **Flaticon** - https://www.flaticon.com/free-icons/continents-map
   - Over 2,368 continent map icons
   - SVG, PSD, PNG, EPS formats

## How to Add Maps:

1. Download continent maps from one of the resources above
2. Save them to this `/public/maps/` folder
3. Name them exactly as shown above (lowercase)
4. Recommended size: 1200-2000px wide
5. Format: PNG or JPG (PNG preferred for transparency)
